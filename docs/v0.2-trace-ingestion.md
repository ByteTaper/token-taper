# TokenTaper v0.2 — Trace Ingestion

Operational guide for v0.2 task trace APIs (starting with task creation).

## Start a task

```http
POST /v1/tasks/start
Content-Type: application/json
```

Creates an `ai_task` row with status `started` and returns the internal `task_id` for span and event ingestion APIs.

### Request body

```json
{
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "external_task_id": "task_01",
  "workflow": "support_ticket_agent",
  "task_type": "agentic_workflow",
  "started_at": "2026-06-05T10:00:00Z",
  "metadata": {
    "environment": "dev",
    "source": "agent-orchestrator"
  }
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `tenant_id` | yes | UUID string |
| `external_task_id` | no | Unique per tenant when set |
| `workflow` | no | Workflow name |
| `task_type` | no | e.g. `agentic_workflow` |
| `started_at` | no | RFC3339; server time if omitted |
| `metadata` | no | Defaults to `{}` |

### Success response (`201 Created`)

Flat JSON (no `data` / `error` envelope):

```json
{
  "task_id": "11111111-1111-1111-1111-111111111111",
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "external_task_id": "task_01",
  "workflow": "support_ticket_agent",
  "task_type": "agentic_workflow",
  "status": "started",
  "started_at": "2026-06-05T10:00:00.000Z",
  "finished_at": null,
  "metadata": {
    "environment": "dev",
    "source": "agent-orchestrator"
  }
}
```

### Error responses

| Status | `error` | When |
|--------|---------|------|
| `400` | `validation_error` | Invalid or missing fields, malformed JSON |
| `409` | `task_conflict` | Duplicate `external_task_id` for the same tenant |
| `500` | (internal) | Unexpected server error |

Validation example:

```json
{
  "error": "validation_error",
  "message": "Invalid task start request.",
  "details": [
    {"field": "tenant_id", "reason": "missing required key"}
  ]
}
```

Conflict example:

```json
{
  "error": "task_conflict",
  "message": "Task with the same external_task_id already exists for this tenant.",
  "details": [
    {"field": "external_task_id", "reason": "duplicate"}
  ]
}
```

### Example

```bash
curl -s -X POST http://localhost:8080/v1/tasks/start \
  -H 'Content-Type: application/json' \
  -d '{
    "tenant_id": "00000000-0000-0000-0000-000000000001",
    "external_task_id": "task_01",
    "workflow": "support_ticket_agent",
    "task_type": "agentic_workflow",
    "metadata": {"environment": "dev"}
  }' | jq .
```

Requires a running API with migrations applied and a valid `tenant_id` row in PostgreSQL.
