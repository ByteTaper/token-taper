# TokenTaper v0.2 — Trace Ingestion

Operational guide for v0.2 task trace APIs (starting with task creation).

## Start a task

```http
POST /v1/tasks/start
Content-Type: application/json
```

Creates an `ai_task` row with status `started` and returns the internal `task_id` for span and event ingestion APIs.

### Request body

```json
{
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "external_task_id": "task_01",
  "workflow": "support_ticket_agent",
  "task_type": "agentic_workflow",
  "started_at": "2026-06-05T10:00:00Z",
  "metadata": {
    "environment": "dev",
    "source": "agent-orchestrator"
  }
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `tenant_id` | yes | UUID string |
| `external_task_id` | no | Unique per tenant when set |
| `workflow` | no | Workflow name |
| `task_type` | no | e.g. `agentic_workflow` |
| `started_at` | no | RFC3339; server time if omitted |
| `metadata` | no | Defaults to `{}` |

### Success response (`201 Created`)

Flat JSON (no `data` / `error` envelope):

```json
{
  "task_id": "11111111-1111-1111-1111-111111111111",
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "external_task_id": "task_01",
  "workflow": "support_ticket_agent",
  "task_type": "agentic_workflow",
  "status": "started",
  "started_at": "2026-06-05T10:00:00.000Z",
  "finished_at": null,
  "metadata": {
    "environment": "dev",
    "source": "agent-orchestrator"
  }
}
```

### Error responses

| Status | `error` | When |
|--------|---------|------|
| `400` | `validation_error` | Invalid or missing fields, malformed JSON |
| `409` | `task_conflict` | Duplicate `external_task_id` for the same tenant |
| `500` | (internal) | Unexpected server error |

Validation example:

```json
{
  "error": "validation_error",
  "message": "Invalid task start request.",
  "details": [
    {"field": "tenant_id", "reason": "missing required key"}
  ]
}
```

Conflict example:

```json
{
  "error": "task_conflict",
  "message": "Task with the same external_task_id already exists for this tenant.",
  "details": [
    {"field": "external_task_id", "reason": "duplicate"}
  ]
}
```

### Example

```bash
curl -s -X POST http://localhost:8080/v1/tasks/start \
  -H 'Content-Type: application/json' \
  -d '{
    "tenant_id": "00000000-0000-0000-0000-000000000001",
    "external_task_id": "task_01",
    "workflow": "support_ticket_agent",
    "task_type": "agentic_workflow",
    "metadata": {"environment": "dev"}
  }' | jq .
```

Requires a running API with migrations applied and a valid `tenant_id` row in PostgreSQL.

## Finish a task

```http
POST /v1/tasks/{task_id}/finish
Content-Type: application/json
```

Transitions a `started` task to a terminal status (`finished`, `failed`, or `cancelled`). Merges request `metadata` into the existing task metadata.

### Path parameters

| Parameter | Required | Notes |
|-----------|----------|-------|
| `task_id` | yes | UUID from `POST /v1/tasks/start` |

### Request body

```json
{
  "status": "finished",
  "finished_at": "2026-06-05T10:10:00Z",
  "metadata": {
    "result": "success",
    "summary": "Support ticket response generated"
  }
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `status` | yes | `finished`, `failed`, or `cancelled` (not `started`) |
| `finished_at` | no | RFC3339; server time if omitted |
| `metadata` | no | Defaults to `{}`; merged with existing metadata |

### Success response (`200 OK`)

```json
{
  "task_id": "11111111-1111-1111-1111-111111111111",
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "external_task_id": "task_01",
  "workflow": "support_ticket_agent",
  "task_type": "agentic_workflow",
  "status": "finished",
  "started_at": "2026-06-05T10:00:00.000Z",
  "finished_at": "2026-06-05T10:10:00.000Z",
  "metadata": {
    "environment": "dev",
    "result": "success"
  }
}
```

### Error responses

| Status | `error` | When |
|--------|---------|------|
| `400` | `validation_error` | Invalid `task_id`, body, or terminal status |
| `404` | `task_not_found` | No task with that `task_id` |
| `409` | `task_conflict` | Task already in a terminal status |
| `500` | (internal) | Unexpected server error |

Not found example:

```json
{
  "error": "task_not_found",
  "message": "Task was not found.",
  "details": [
    {"field": "task_id", "reason": "not_found"}
  ]
}
```

Conflict example:

```json
{
  "error": "task_conflict",
  "message": "Task is already in a terminal status.",
  "details": [
    {"field": "status", "reason": "already_terminal"}
  ]
}
```

### Example

```bash
TASK_ID="<task_id from start>"
curl -s -X POST "http://localhost:8080/v1/tasks/${TASK_ID}/finish" \
  -H 'Content-Type: application/json' \
  -d '{
    "status": "finished",
    "metadata": {"result": "success"}
  }' | jq .
```

## Get task detail

```http
GET /v1/tasks/{task_id}
```

Returns the current `ai_task` row (any status).

### Success response (`200 OK`)

```json
{
  "task_id": "11111111-1111-1111-1111-111111111111",
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "external_task_id": "task_01",
  "workflow": "support_ticket_agent",
  "task_type": "agentic_workflow",
  "status": "finished",
  "started_at": "2026-06-05T10:00:00.000Z",
  "finished_at": "2026-06-05T10:00:12.000Z",
  "metadata": {"environment": "dev"},
  "created_at": "2026-06-05T10:00:00.000Z",
  "updated_at": "2026-06-05T10:00:12.000Z"
}
```

### Error responses

| Status | `error` | When |
|--------|---------|------|
| `400` | `validation_error` | Invalid `task_id` UUID |
| `404` | `task_not_found` | No task with that `task_id` |

### Example

```bash
curl -s "http://localhost:8080/v1/tasks/${TASK_ID}" | jq .
```

## Get task trace

```http
GET /v1/tasks/{task_id}/trace
```

Returns the task plus all spans and events for that task in deterministic order (flat arrays; use `parent_span_id` to build a tree client-side).

Spans are ordered by `started_at`, then `created_at`. Events are ordered by `occurred_at`, then `created_at`.

If the task exists but has no spans or events yet, the response is `200 OK` with empty `spans` and `events` arrays (not `404`).

### Success response (`200 OK`)

```json
{
  "task": {
    "task_id": "11111111-1111-1111-1111-111111111111",
    "tenant_id": "00000000-0000-0000-0000-000000000001",
    "status": "started",
    "started_at": "2026-06-05T10:00:00.000Z",
    "finished_at": null,
    "metadata": {}
  },
  "spans": [],
  "events": []
}
```

### Error responses

| Status | `error` | When |
|--------|---------|------|
| `400` | `validation_error` | Invalid `task_id` UUID |
| `404` | `task_not_found` | No task with that `task_id` |

### Example

```bash
curl -s "http://localhost:8080/v1/tasks/${TASK_ID}/trace" | jq .
```

## Record LLM call event

```http
POST /v1/events/llm-call
Content-Type: application/json
```

Records one `llm_call` row in `ai_event`, linked to an existing task and optionally a span.

### Request body

```json
{
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "task_id": "11111111-1111-1111-1111-111111111111",
  "span_id": "22222222-2222-2222-2222-222222222222",
  "external_event_id": "evt_llm_01",
  "provider": "anthropic",
  "model": "claude-sonnet",
  "input_tokens": 3000,
  "output_tokens": 700,
  "cached_tokens": 0,
  "latency_ms": 3400,
  "status": "success",
  "occurred_at": "2026-06-05T10:00:03Z",
  "metadata": {
    "temperature": 0.2
  }
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `tenant_id` | yes | Must match the task's tenant |
| `task_id` | yes | Existing task from `POST /v1/tasks/start` |
| `span_id` | no | Must belong to the same task when set |
| `provider`, `model` | yes | Provider and model identifiers |
| `input_tokens`, `output_tokens`, `latency_ms` | yes | Non-negative integers (`0` allowed on failures) |
| `status` | yes | `success`, `failure`, `timeout`, `cancelled`, or `skipped` |
| `occurred_at` | no | RFC3339; server time if omitted |
| `metadata` | no | Defaults to `{}` |

### Success response (`201 Created`)

Flat JSON (no `data` / `error` envelope). `event_type` is always `llm_call`:

```json
{
  "event_id": "33333333-3333-3333-3333-333333333333",
  "tenant_id": "00000000-0000-0000-0000-000000000001",
  "task_id": "11111111-1111-1111-1111-111111111111",
  "span_id": "22222222-2222-2222-2222-222222222222",
  "external_event_id": "evt_llm_01",
  "event_type": "llm_call",
  "provider": "anthropic",
  "model": "claude-sonnet",
  "input_tokens": 3000,
  "output_tokens": 700,
  "cached_tokens": 0,
  "latency_ms": 3400,
  "status": "success",
  "error_code": null,
  "error_message": null,
  "occurred_at": "2026-06-05T10:00:03Z",
  "metadata": {
    "temperature": 0.2
  }
}
```

### Error responses

| Status | `error` | When |
|--------|---------|------|
| `400` | `validation_error` | Invalid body, tenant mismatch, span on wrong task |
| `404` | `task_not_found` | Unknown `task_id` |
| `404` | `span_not_found` | Unknown `span_id` |
| `409` | `event_conflict` | Duplicate `external_event_id` for tenant |

Failed call example (still `201` when valid):

```json
{
  "status": "failure",
  "input_tokens": 1200,
  "output_tokens": 0,
  "latency_ms": 900,
  "error_code": "provider_error",
  "error_message": "Provider returned 500"
}
```

### Example

```bash
curl -s -X POST http://localhost:8080/v1/events/llm-call \
  -H 'Content-Type: application/json' \
  -d '{
    "tenant_id": "00000000-0000-0000-0000-000000000001",
    "task_id": "'"${TASK_ID}"'",
    "provider": "anthropic",
    "model": "claude-sonnet",
    "input_tokens": 3000,
    "output_tokens": 700,
    "latency_ms": 3400,
    "status": "success"
  }' | jq .
```
