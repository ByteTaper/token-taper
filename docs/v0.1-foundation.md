# TokenTaper v0.1 Foundation

Operational guide for the v0.1 service foundation: Docker Compose startup, migrations, endpoint verification, smoke tests, logs, and troubleshooting.

## Purpose

TokenTaper v0.1 is the **standalone Clojure backend service foundation** for AI cost governance. It proves the runtime shell—HTTP server, configuration, PostgreSQL, migrations, health, metrics, structured logging, system metadata, container packaging, and CI—before product-domain features land.

v0.1 does **not** implement business workflows. It answers: *can we run, observe, and verify a healthy service process?*

## Included in v0.1

- Clojure service skeleton (`token-taper` namespace, `token_taper` paths)
- Integrant lifecycle and EDN/Aero configuration (`TOKEN_TAPER_*` env vars)
- Ring / Reitit / Jetty HTTP server
- PostgreSQL datasource (HikariCP, next.jdbc)
- Migratus database migrations
- Health and readiness endpoints (`/health/live`, `/health/ready`)
- Prometheus metrics endpoint (`/metrics`, `tokentaper_*` metric names)
- JSON structured logging (NDJSON on stderr)
- System info endpoint (`GET /v1/system/info`)
- Dockerfile and Docker Compose runtime (`tokentaper-api`, `postgres`)
- Basic GitHub Actions CI (tests, uberjar, Docker build, Compose smoke)
- Smoke test script ([`scripts/smoke-v0.1.sh`](../scripts/smoke-v0.1.sh))

## Not included in v0.1

## Start with Docker Compose

From the repository root:

```bash
cp .env.example .env
docker compose up -d postgres
docker compose run --rm tokentaper-api migrate
docker compose up -d tokentaper-api
```

**Important:** Run migrations **before** expecting `/health/ready` to return `200`. Readiness checks PostgreSQL and the `schema_migrations` table; without migrate, ready returns `503`.

If host port `5432` is already in use, set `POSTGRES_PORT=5433` in `.env` before starting Postgres.

**Makefile shortcuts:**

```bash
make docker-up      # postgres + migrate + API
make docker-smoke   # ./scripts/smoke-v0.1.sh (API must already be running)
```

Environment variables use the `TOKEN_TAPER_*` prefix (see [`.env.example`](../.env.example)). Compose loads `.env` from the project root when present.

## Run database migrations

Apply SQL migrations to the Compose Postgres service:

```bash
docker compose run --rm tokentaper-api migrate
```

Or:

```bash
make docker-migrate
```

Migrations live in [`migrations/`](../migrations/) at the project root. The container uses `TOKEN_TAPER_MIGRATION_DIR=migrations` by default.

## Start API service

After Postgres is healthy and migrations have run:

```bash
docker compose up -d tokentaper-api
```

Or use `make docker-up`, which starts Postgres, runs migrate, and starts the API.

The `tokentaper-api` service exposes port `8080` on the host and defines a container healthcheck against `GET /health/live`.

## Verify endpoints

After a successful migrate and API start, these should return **HTTP 200**:

```bash
curl -i http://localhost:8080/health/live
curl -i http://localhost:8080/health/ready
curl -i http://localhost:8080/metrics
curl -i http://localhost:8080/v1/system/info
```

| Path | Role |
|------|------|
| `/health/live` | Liveness (process up; no DB) |
| `/health/ready` | Readiness (config, DB, migrations) |
| `/metrics` | Prometheus text exposition |
| `/v1/system/info` | Service/build/runtime metadata (flat JSON) |

## Run smoke test

Automated v0.1 verification (status codes + metric/system-info body checks):

```bash
BASE_URL=http://localhost:8080 ./scripts/smoke-v0.1.sh
```

Expected final line:

```text
[smoke-v0.1] v0.1 smoke test passed
```

With the stack already up:

```bash
make docker-smoke
```

CI runs the same script after `docker compose up -d --wait tokentaper-api` (see [`.github/workflows/ci.yml`](../.github/workflows/ci.yml)).

## Inspect logs

API logs are structured JSON (NDJSON) on stderr:

```bash
docker compose logs tokentaper-api
```

Look for events such as:

- `service_starting`
- `service_started`
- `http_request_completed`

Default log format is JSON (`TOKEN_TAPER_LOG_FORMAT=json`). Set `TOKEN_TAPER_LOG_LEVEL` for verbosity (`debug`, `info`, `warn`, `error`, `fatal`).

## Metrics verification

Confirm core Prometheus series are present:

```bash
curl -s http://localhost:8080/metrics | grep tokentaper_uptime_seconds
curl -s http://localhost:8080/metrics | grep tokentaper_http_requests_total
curl -s http://localhost:8080/metrics | grep tokentaper_database_ready
```

Metrics use the `tokentaper_` prefix. `/metrics` returns plain text (`text/plain; version=0.0.4`), not JSON.

## Reset local environment

Stop containers:

```bash
docker compose down
```

Stop containers **and** delete the named PostgreSQL volume (fresh DB on next start):

```bash
docker compose down -v
```

| Command | Effect |
|---------|--------|
| `docker compose down` | Stops containers; keeps `tokentaper-postgres-data` volume |
| `docker compose down -v` | Stops containers and removes local PostgreSQL data |

Or: `make docker-down` (stops without `-v`).

## Troubleshooting

### `/health/live` fails

**Possible causes:**

- API service is not running
- Port `8080` is unavailable on the host
- Container failed to start

**Commands:**

```bash
docker compose ps
docker compose logs tokentaper-api
```

### `/health/ready` returns `503`

**Possible causes:**

- PostgreSQL is not running
- Database connection config is wrong (`TOKEN_TAPER_DATABASE_*`)
- Migrations have not run
- `schema_migrations` table is missing

**Commands:**

```bash
docker compose ps postgres
docker compose logs postgres
docker compose run --rm tokentaper-api migrate
```

### `/metrics` fails

**Possible causes:**

- Metrics registry failed to initialize
- API service is not running
- Route not registered

**Commands:**

```bash
curl -i http://localhost:8080/metrics
docker compose logs tokentaper-api
```

### Docker image build fails

**Possible causes:**

- Invalid `deps.edn` or `build.clj`
- Dockerfile missing required files
- `.dockerignore` excludes required paths

**Commands:**

```bash
docker build --no-cache -t tokentaper:debug .
```

Host build check:

```bash
clojure -T:build uber
```

### Migration fails

**Possible causes:**

- PostgreSQL unavailable
- Database URL or credentials incorrect
- Migration SQL error
- Migration partially applied

**Commands:**

```bash
docker compose logs postgres
docker compose run --rm tokentaper-api migrate
```

## v0.1 Exit Criteria

Before treating v0.1 foundation as complete, verify:

- [ ] `clojure -M:test` passes (unit tests; integration tests optional with test DB)
- [ ] `clojure -T:build uber` produces `target/tokentaper.jar`
- [ ] `docker build -t tokentaper:ci .` succeeds
- [ ] Docker Compose stack starts: Postgres → migrate → API
- [ ] `./scripts/smoke-v0.1.sh` exits 0 against `http://localhost:8080`
- [ ] GitHub Actions **Build, test, and package** job is green
- [ ] `/health/live`, `/health/ready`, `/metrics`, `/v1/system/info` return 200 after migrate
- [ ] Metrics expose `tokentaper_uptime_seconds`, `tokentaper_http_requests_total`, `tokentaper_database_ready`
- [ ] Logs show JSON events (`service_starting`, `service_started`, `http_request_completed`)
